Glyphrun: level 1 walkthrough

Scripted simulation, not a player. Kanagawa theme colours. This is the visual target for the real game.

run · seed 7f3a-91c2
P or Esc pauses the demo

What to watch for

  1. Collecting bits: 0 and 1 burst and score pops up.
  2. sudo power-up: one bit hides a second @, the hero grows to @@.
  3. Stomp: the bug breaks into fragments and the screen shakes.
  4. Zombie hit: glitch, the hero shrinks back to one @ and blinks.
  5. Checkpoint, exit 0 and the level summary.
  6. Falling into /dev/null on the last life: segfault and the same-seed / new-seed choice.
